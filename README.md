Lilith AI – Intelligent Chat Agent Platform
Tech Stack: React (Frontend), Node.js, Express.js, MongoDB Atlas (Backend & Database)
Role: Full Stack Developer

Developed an advanced AI-powered chat platform named Lilith AI, where users can sign up or log in via a secure interface (user: Clark) and interact with a multilingual AI agent. The system supports:

Natural language conversations in any language, powered by AI.

Persistent chat history, allowing users to view past interactions.

Clean and responsive UI built with React for an intuitive user experience.

Robust backend with Node.js and Express, handling authentication, session management, and chat storage.

MongoDB Atlas as a cloud database to store user data and chat logs securely.

The project showcases strong integration between frontend and backend systems, real-time AI interaction capabilities, and effective use of cloud-based databases for scalable data management.
